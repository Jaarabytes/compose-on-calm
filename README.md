# Cocalm

Watermark videos in your browser. Zero server code needed.

## Development

**NOTE:** Do not update the packages. FFmpeg wasm of versions `0.12.6` only works in nextjs and nodejs environments

## Installation

Prerequisites:
- pnpm installed

To install, run the following:
```
git clone https://github.com/Jaarabytes/compose-on-calm.git
cd compose-on-calm
pnpm install
pnpm run dev
```

Proceed to check `localhost:3000` on your local browser
